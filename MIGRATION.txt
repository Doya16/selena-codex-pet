赛琳娜 Codex 桌宠 · Windows 便携版

1. 在 Windows 10/11 x64 上安装并登录 Codex。
2. 完整解压 ZIP 到可写目录，双击「一键部署.cmd」；它会检查文件、创建桌面和开始菜单快捷方式并启动赛琳娜。也可以直接双击 赛琳娜Codex桌宠启动.exe。
3. 设置 → 连接 Codex → 跟随的会话 → 自动跟随最近活动。
4. 交互工作室：为每种动作设置 GIF、播放、气泡和语音。
5. GIF 素材 → 打开素材目录；放入 GIF/WebP/PNG/JPG/JPEG 后刷新并选择。
6. 语音支持 WAV/MP3/OGG/FLAC/M4A/AAC；字体支持 TTF/OTF/TTC。
7. 右键 → 设置 → 字体与大小，或 Ctrl + 滚轮实时缩放。
8. 设置 → 保存与迁移，可保存、导入或导出全部配置和素材。

首次启动使用附带的默认配置：16 个交互事件已配好花嫁表情和赛琳娜语音。设置 → 默认表情风格可切换「花嫁」或「原皮」。声音默认开启、音量 10%，可在声音页调整。
修改自动保存在 settings.json；GIF、字体、音频和默认配置随 ZIP 迁移。
再次迁移请导出 Windows 便携完整包，在新电脑完整解压后运行。

首次正常启动会创建桌面快捷方式。误删后：设置 → 保存与迁移 → 创建桌面快捷方式，或再双击一次「一键部署.cmd」。图标样式在设置 → 桌面与声音选择，会随配置一起迁移。

设置 → 版本与更新可选自动／GitHub／镜像加速；发现新版时可一键下载、校验签名、更新并重启。连接页面可设置随客户端完全退出而关闭。
