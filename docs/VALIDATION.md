# v1.0.4 · 稍后再提醒的时长可以自己填

- **稍后再提醒**：休息提醒卡片上的“稍后再提醒”原来固定等 30 分钟。现在在 **设置 → 桌面与声音 → 休息提醒 → 稍后再提醒** 里填 1～240 分钟（默认 30），卡片按钮显示成“N 分钟后再提醒”，点它就按 N 分钟后再提醒；设置页的预览也按这个数字显示。

# v1.0.2 · 台词一旦开始就完整说完

- **台词不再被打断**：v1.0.1 中，她说待机、摸头、双击等台词时再点、双击、拖动或递奶茶，会让原来的台词淡出、换成新的回应，所以长台词（例如 6.6 秒的待机台词）可能说到一半就停。现在一句台词开始后总会说完：说话时的互动照常显示动作，但不出声，原来的台词继续。
- **台词的表情会回来**：互动动作结束时，如果原来的台词还没说完，就回到这句台词的表情，直到说完；完成、出错、暂停和等你回应的台词同样如此。正在进行的任务表情（思考、查阅、编辑、执行）不会被盖住，台词照常说完。
- **语音记录**：程序目录下的 `voice-log.txt` 记录每句台词的开始、结束（实际播放秒数 / 台词长度）以及被什么停止，只保留最近几百条，便于查明某句为什么没说完。
- 只有主动试听、停止声音、静音和全屏隐藏会中断正在说的台词。
